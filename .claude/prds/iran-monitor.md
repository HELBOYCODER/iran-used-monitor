# قرارداد تحویل

درخواست: بومی‌سازی ai-goofish-monitor، پنل فارسی و RTL، اتصال بازارهای ایرانی، تست و انتشار عمومی در حساب HELBOYCODER.

## تصمیم اجرایی و محدوده
- سورس MIT بالادستی با تاریخچه و حقوق مؤلف حفظ می‌شود؛ حالت ایرانی مستقل از Playwright و زیرساخت اختصاصی Xianyu در `iran_monitor/` و `iran_web/` افزوده می‌شود. پنل چینی قدیمی به‌عنوان آرشیو بالادستی باقی می‌ماند، نه رابط ایرانی.
- Python 3.11+ و کتابخانه استاندارد؛ SQLite، API، زمان‌بندی، حذف تکرار، فیلتر قیمت تومان، هوش مصنوعی اختیاری با OpenAI-compatible.
- اتصال «تمام» بازارهای ایران معیار قابل تضمین نیست. ماتریس منابع، وضعیت واقعی و محدودیت هر اتصال باید منتشر شود. منبع فاقد دسترسی عمومی یا نیازمند قرارداد، متصل معرفی نمی‌شود.
- احراز هویت API با توکن، عدم انتشار اسرار، عدم دورزدن ورود/کپچا و عدم جمع‌آوری شماره تماس.

## معیار پذیرش
1. نصب مستقیم بدون پکیج اضافی و مسیر Docker مجزا روی پورت ۸۰۰۰.
2. پنل فارسی راست‌چین موبایل و دسکتاپ با عملیات واقعی پایش و نمایش خطای شبکه.
3. تست واحد و API با SQLite موقت و شبکه شبیه‌سازی‌شده؛ تست زنده منابع جداگانه گزارش شود.
4. مجوز MIT و انتساب بالادستی محفوظ، README فارسی، راهنمای امنیت و توسعه اتصال‌ها.
5. انتشار در مخزن عمومی HELBOYCODER/iran-used-monitor و Release با شرح فارسی؛ نه انتشار در مخزن اصلی.
6. هیچ داده نمونه‌ای به‌عنوان آگهی زنده نمایش داده نشود. نتیجه آزمایش Docker فقط در صورت اجرای واقعی ادعا شود.
