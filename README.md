# دست‌دوم‌بان | پایش هوشمند آگهی‌های ایران

پنل فارسی و راست‌چین برای ساخت جست‌وجوهای پایش، فیلتر قیمت به تومان، نگهداری آگهی‌ها و ارزیابی اختیاری با مدل‌های سازگار با OpenAI.

**وضعیت: نسخه اولیه ایرانی؛ اتصال همه بازارهای ایران یا پایداری APIهای غیررسمی تضمین نشده است.** وضعیت دقیق هر منبع و نتیجه آزمایش شبکه در [ماتریس منابع](docs/IRAN-SOURCES.md) ثبت می‌شود. آگهی آزمایشی به‌عنوان داده واقعی نمایش داده نمی‌شود.

این مخزن بر پایه [ai-goofish-monitor](https://github.com/Usagi-org/ai-goofish-monitor) با مجوز MIT منتشر شده است. حالت ایرانی مستقل از خزنده Xianyu اجرا می‌شود؛ [منشأ و تفاوت‌ها](docs/UPSTREAM-FA.md). مستندات برنامه اصلی: [چینی](README_UPSTREAM_ZH.md) و [انگلیسی](README_EN.md).

## امکانات حالت ایرانی

- رابط فارسی، راست‌چین و واکنش‌گرا؛ بدون CDN یا فرانت‌اند نیازمند build.
- پایش‌های مستقل با عبارت، شهر، منبع، بازه قیمت و فاصله اجرا.
- SQLite، حذف تکرار و نگهداری نتایج؛ نیازی به PostgreSQL یا Redis نیست.
- هوش مصنوعی اختیاری؛ پایش و فیلتر عادی بدون کلید AI کار می‌کند.
- API محافظت‌شده با توکن؛ داده نمونه یا اتصال موفق ساختگی ندارد.
- بسته Docker مجزا و اجرای مستقیم با Python 3.11 به بالا، بدون نصب وابستگی پایتون.

## اجرای مستقیم

```sh
git clone https://github.com/HELBOYCODER/iran-used-monitor.git
cd iran-used-monitor
export IRAN_MONITOR_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
python3 -m iran_monitor
```

نشانی پنل: **http://127.0.0.1:8000**. مقدار متغیر `IRAN_MONITOR_TOKEN` را در بخش اتصال پنل وارد کنید. توکن را در محل خصوصی خود ذخیره کنید؛ در هر بار تولید مجدد، توکن قبلی دیگر معتبر نیست. اجرای مستقیم متغیرهای محیطی را می‌خواند، نه الزاماً فایل `.env`.

## اجرای Docker Compose

```sh
git clone https://github.com/HELBOYCODER/iran-used-monitor.git
cd iran-used-monitor
python3 -c 'import secrets; from pathlib import Path; p=Path(".env"); p.touch(exist_ok=False); p.chmod(0o600); p.write_text("IRAN_MONITOR_TOKEN="+secrets.token_urlsafe(32)+"\n")'
docker compose -f compose.iran.yaml up -d --build
```

توکن در فایل خصوصی `.env` ذخیره شده است؛ آن را در قسمت اتصال پنل وارد کنید. اگر از قبل `.env` دارید، فرمان تولید فایل عمداً آن را بازنویسی نمی‌کند؛ `IRAN_MONITOR_TOKEN` را به همان فایل اضافه کنید.

**توجه:** `docker-compose.yaml` قدیمی مربوط به Xianyu است. برای نسخه ایرانی حتماً `-f compose.iran.yaml` را بدهید. داده‌های Docker در volume به نام `iran-data` نگهداری می‌شوند. حذف volume داده‌ها را پاک می‌کند.

```sh
docker compose -f compose.iran.yaml logs --tail 100
docker compose -f compose.iran.yaml down
```

## فعال‌سازی خوراک‌های آزمایشی ایسام و کمدا

این اتصال‌ها خوراک محدود اولین صفحه را می‌خوانند و عبارت را محلی فیلتر می‌کنند؛ جستجوی کامل بازار یا فیلتر شهر نیستند. پس از بررسی [شرایط منابع](docs/IRAN-SOURCES.md)، در اجرای مستقیم:

```sh
export IRAN_MONITOR_EXPERIMENTAL_SOURCES=1
python3 -m iran_monitor
```

در Docker همین متغیر را به `.env` اضافه کنید و سرویس را دوباره اجرا کنید. سپس از پنل منبع ایسام یا کمدا را انتخاب و پایش دستی اجرا کنید. اگر شهر داده در منبع موجود نباشد، نتیجه نباید به تهران منتسب شود.

زمان‌بندی و AI پیش‌فرض خاموش‌اند؛ از تنظیمات پنل آن‌ها را آگاهانه فعال کنید. اعلان نسخه اولیه، صندوق اعلان داخل پنل است؛ ارسال تلگرام/پیامک و اعلان در زمان بسته‌بودن مرورگر در این نسخه پیاده‌سازی نشده است.

## راه‌اندازی هوش مصنوعی

این تنظیم اختیاری است. در اجرای مستقیم متغیرها را export کنید؛ در Docker آن‌ها را به `.env` اضافه کنید:

```sh
export OPENAI_BASE_URL=https://api.openai.com/v1
export OPENAI_MODEL=gpt-4o-mini
read -r -s OPENAI_API_KEY
export OPENAI_API_KEY
python3 -m iran_monitor
```

فرمان `read -s` در Bash پشتیبانی می‌شود. کلید خود را در تنظیمات محیط سیستم یا فایل خصوصی وارد کنید؛ هرگز داخل مخزن قرار ندهید. سرویس سازگار دیگری هم قابل استفاده است. هزینه و سیاست حریم خصوصی تابع ارائه‌دهنده انتخابی شماست.

## استفاده

۱. پنل را باز و توکن اتصال را وارد کنید.
۲. در بخش منابع، وضعیت واقعی اتصال را ببینید؛ «بررسی‌نشده» یا خطا به معنی اتصال موفق نیست.
۳. پایش جدید بسازید؛ شهر را با شناسه مورد انتظار منبع، مانند `tehran`، وارد کنید. قیمت‌ها به تومان‌اند.
۴. یک بار پایش دستی اجرا کنید؛ اگر منبع در شبکه شما پاسخ ندهد، پیام خطا را بررسی کنید.
۵. سپس پایش زمان‌بندی‌شده را فعال نگه دارید. برنامه باید در حال اجرا بماند.

خروجی AI توصیه قطعی خرید یا تضمین سلامت کالا نیست. درباره قیمت توافقی/نامشخص و معنای فیلدهای منبع، راهنمای منابع را ببینید.

## آزمون‌ها

```sh
python3 -m unittest discover -s tests/iran -v
python3 -m compileall -q iran_monitor
node --check iran_web/app.js
```

Node فقط برای بررسی کد رابط در توسعه است، نه اجرای محصول. تست‌های ایرانی از تست‌های بالادستی جدا هستند؛ موفقیت آن‌ها به معنی تست شدن کل برنامه قدیمی یا دسترسی زنده به همه بازارها نیست. [گزارش آزمون](docs/IRAN-TESTS.md).
