# امنیت و حریم خصوصی دست‌دوم‌بان

- پنل برای استفاده شخصی و تک‌کاربره است؛ سامانه چندمستأجری نیست.
- API بدون `IRAN_MONITOR_TOKEN` نباید اجرا شود. توکن بلند تصادفی بسازید؛ در کد، Issue، تصویر یا مخزن قرار ندهید.
- تنظیمات هوش مصنوعی از متغیر محیطی خوانده می‌شوند. API نباید کلیدها را بازگرداند. اطلاعات آگهی در صورت فعال‌سازی AI به ارائه‌دهنده انتخابی شما ارسال می‌شود.
- پورت Compose فقط روی `127.0.0.1` باز است. برای اینترنت از پراکسی HTTPS با کنترل دسترسی و محدودیت درخواست استفاده کنید. بازکردن مستقیم پورت توصیه نمی‌شود.
- داده SQLite را خصوصی نگه دارید. نسخه پشتیبان ممکن است شامل عبارت‌های جست‌وجو و علایق خرید شما باشد.
- هیچ شماره تماس، حساب کاربری بازار یا کوکی ورود برای حالت ایرانی لازم نیست. کپچا یا محدودیت دسترسی دور زده نمی‌شود.
- اتصال عمومی و غیررسمی تضمین پایداری ندارد؛ تغییر ساختار یا مسدودی باید به خطای واضح تبدیل شود، نه نتیجه ساختگی.
- ورودی آگهی و پاسخ مدل قابل اعتماد نیستند. لینک‌ها و تصاویر باید اعتبارسنجی و متن‌ها بدون اجرای HTML رندر شوند.
- کد بالادستی Xianyu برای حفظ منشأ در مخزن باقی مانده است؛ بسته Docker ایرانی آن را اجرا یا نصب نمی‌کند. بررسی امنیت حالت ایرانی به معنی ممیزی کامل کد قدیمی نیست.

## گزارش مشکل

برای آسیب‌پذیری، جزئیات و کلید یا داده شخصی را در Issue عمومی نفرستید؛ از کانال خصوصی مالک مخزن استفاده کنید. این پروژه به خدمات دیوار، شیپور یا سایر بازارها وابسته یا مورد تأیید آن‌ها نیست.
