# گزارش آزمون نسخه ایرانی

این گزارش فقط حالت `iran_monitor` و `iran_web` را پوشش می‌دهد. کد قدیمی Xianyu به‌طور کامل در این محیط اجرا نشده است.

## تفکیک سطح شواهد

- تست واحد: نرمال‌سازی اعداد و قیمت، اعتبارسنجی، فیلتر و پارسر پاسخ نمونه.
- تست یکپارچگی محلی: API با پایگاه SQLite موقت و احراز هویت؛ هیچ دیتابیس واقعی کاربر برای تست استفاده نمی‌شود.
- تست رابط: اجرای پنل در مرورگر و بررسی عملیات و واکنش‌گرایی.
- تست زنده: درخواست شبکه به بازار واقعی، با گزارش خطا/موفقیت؛ جایگزین تست واحد نیست.
- Docker: محیط محلی Android/PRoot فاقد daemon داکر است؛ build و smoke باید روی GitHub Actions یا میزبان Docker انجام شود. وجود Dockerfile به‌تنهایی گواه اجرای موفق نیست.

نتایج نهایی پس از یکپارچه‌سازی در ادامه همین سند ثبت می‌شوند.

## نتیجه یکپارچه‌سازی ۸ نوامبر ۲۰۲۶

- Python 3.12.15: **۲۷ آزمون بک‌اند + ۱۱ آزمون پل JSON + ۵ آزمون رابط + ۴ آزمون بسته انتشار = ۴۷ آزمون موفق**.
- `compileall` بک‌اند و `node --check iran_web/app.js` موفق.
- پنل در مرورگر واقعی به API و SQLite موقت متصل شد: ورود توکن تست، ساخت پایش ایسام، اسکن زنده، نمایش شمار ۱۰ آگهی و ۱۰ اعلان خوانده‌نشده موفق بود؛ source به connected تغییر کرد.
- عرض ۱۴۴۰ بررسی شد؛ `scrollWidth == innerWidth` و overflow افقی وجود نداشت. عامل رابط عرض ۴۱۲ را نیز با fixture بررسی کرد.
- تست‌های fixture مرورگر عامل رابط: ساخت، ویرایش، توقف، حذف پایش، خواندن اعلان، ذخیره تنظیمات و نمایش امن HTML مخرب موفق.
- اتصال زنده `scan_source` با `IRAN_MONITOR_TRUST_SYSTEM_DNS=1` و opt-in آزمایشی: دیوار ۲۳ کارت، شیپور ۲۶ کارت، ایسام ۱۰ کارت، کمدا ۱۸ کارت استخراج کرد. تعدادها لحظه‌ای‌اند؛ پوشش کامل بازار یا پایداری تضمین نمی‌شود.
- پل JSON از بک‌اند واقعی: ایسام fetched=10/matched=10؛ کمدا fetched=18/matched=16 با عبارت عمومی «ا». جزئیات آگهی در خروجی count-only حذف شد.
- مسیر مستقیم پیش‌فرض در شبکه synthetic این دستگاه fail-closed شد. مسیر DNS سیستم فقط برای چهار میزبان ثابت به‌صورت صریح فعال شد؛ به معنی حذف عمومی کنترل SSRF نیست.
- هیچ تماس پولی با مدل خارجی برای این آزمون‌ها انجام نشد؛ رفتار AI با پاسخ کنترل‌شده تست شده و دسترسی واقعی هر ارائه‌دهنده AI جداگانه به کلید کاربر وابسته است.
- تست کل سورس قدیمی Xianyu، axe، screen reader و بار تولید انجام نشده است.

## CI و Docker

گردش‌کار `.github/workflows/iran-ci.yml` تست Python 3.11/3.12/3.13 و build کانتینر و smoke احراز هویت را تعریف می‌کند. نتیجه واقعی CI باید از تب Actions همین مخزن بررسی شود؛ نتیجه محلی را با موفقیت Docker اشتباه نگیرید.

### تأیید واقعی GitHub Actions

[اجرای موفق 42497574332](https://github.com/HELBOYCODER/iran-used-monitor/actions/runs/42497574332) روی کد `e85fd23`:
- هر سه job پایتون 3.11، 3.12 و 3.13 موفق؛ تست بک‌اند، رابط، پل و بسته انتشار همگی سبز.
- job کانتینر موفق: `docker build -f Dockerfile.iran` و `Container API smoke` واقعاً اجرا شدند.
- smoke داخل کانتینر: health موفق، API بدون توکن 401، API با توکن موفق و صفحه اصلی قابل دریافت.

بنابراین محدودیت نبود daemon محلی با اجرای واقعی CI جبران شد؛ این نتیجه build/smoke است، نه آزمون بار تولید یا تست زنده بازارها داخل Docker.
