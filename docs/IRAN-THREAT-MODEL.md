# مدل تهدید حالت ایرانی

## دارایی‌ها

توکن مدیریت، کلید AI و اعلان، عبارت‌های پایش، فایل SQLite و منابع شبکه میزبان.

## مرزهای اعتماد

| مرز | سوءاستفاده محتمل | کنترل مورد انتظار |
|---|---|---|
| مرورگر ← API | مدیریت بدون مجوز، JSON حجیم، اسکن مکرر | توکن Bearer، سقف بدنه، اعتبارسنجی، قفل اجرای اسکن |
| API ← SQLite | تزریق SQL، حذف ناخواسته | کوئری پارامتری، شناسه و نوع معتبر |
| خزنده ← بازار | پاسخ حجیم، HTML مخرب، تغییر فرمت | timeout، سقف پاسخ، پارسر محدود، خطای صریح |
| سرور ← URL | SSRF و redirect به شبکه خصوصی | دامنه و پروتکل مجاز، رد IP خصوصی، ممنوعیت redirect |
| مرورگر ← آگهی | XSS و لینک javascript | textContent، اعتبارسنجی URL، CSP |
| سرور ← مدل AI | خروجی نامعتبر و prompt injection | خروجی ساختاری، اعتبارسنجی امتیاز، عدم اجرای ابزار/کد |
| سیستم ← انتشار | لو رفتن توکن یا داده کاربر | متغیر محیطی، gitignore، بازبینی فایل‌های staged |

## مرز دامنه این بررسی

حالت ایرانی یک سرویس تک‌کاربره با توکن مشترک است. تفکیک کاربران، سهمیه چندمستأجری، ممیزی قانونی تمام بازارها، تست نفوذ حرفه‌ای و ممیزی تمام سورس Xianyu در دامنه این انتشار نیست. برای دسترسی عمومی به اینترنت به HTTPS و لایه کنترل دسترسی بیرونی نیاز است.

## ریسک باقیمانده

APIهای عمومی غیررسمی می‌توانند بدون اطلاع عوض شوند یا بر اساس IP کشور پاسخ ندهند. تست fixture فقط پارسر را ثابت می‌کند، نه زنده‌بودن سرویس. متن آگهی ممکن است نادرست باشد. AI ممکن است خطا کند و کلید آن هزینه ایجاد کند؛ فعال‌سازی اختیاری است.
