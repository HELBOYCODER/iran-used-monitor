# منشأ پروژه و تفاوت نسخه ایرانی

- پروژه اصلی: https://github.com/Usagi-org/ai-goofish-monitor
- نسخه مبنا: `77f8d75869acd65f9dba72731b95c7c49ea67bdf`
- مجوز: MIT؛ فایل LICENSE و حق مؤلف `Copyright (c) 2025 dingyufei615` بدون تغییر حفظ شده‌اند.
- نسخه ایرانی: دست‌دوم‌بان، در حساب HELBOYCODER.

پروژه اصلی برای Xianyu نوشته شده و به مدل داده، ورود، خزنده و فرانت‌اند همان بازار وابسته است. تغییر ترجمه‌ها به‌تنهایی آن را به ابزار ایرانی تبدیل نمی‌کند. به همین دلیل نسخه ایرانی یک حالت اجرایی مستقل با Python استاندارد، SQLite و پنل فارسی دارد؛ فایل‌های بالادستی برای انتساب و توسعه بعدی حفظ شده‌اند.

این انتشار ترجمه کامل تمام صفحات قدیمی Vue یا پشتیبانی ایرانی از تمام امکانات Xianyu نیست. مسیر پیش‌فرض مستندات جدید، `python -m iran_monitor` و `compose.iran.yaml` است؛ `docker-compose.yaml` قدیمی، برنامه اصلی Xianyu را اجرا می‌کند.

معیار ستاره و فورک پروژه اصلی متعلق به همان پروژه است، نه این نسخه. هیچ وابستگی تجاری یا تأیید رسمی از سوی بازارهای ایران ادعا نمی‌شود.
