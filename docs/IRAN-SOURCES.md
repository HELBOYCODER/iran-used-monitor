# منابع ایرانی و وضعیت واقعی اتصال

تاریخ بررسی: ۸ نوامبر ۲۰۲۶. درخواست‌ها بدون ورود، کوکی یا دورزدن کپچا انجام شده‌اند. HTTP 200 صفحه اصلی به معنی کارکردن جستجو یا مجوز بازنشر نیست. جدول زیر «شواهد شبکه» است؛ قابلیت دقیق پیاده‌سازی در انتهای سند ثبت می‌شود.

| منبع | شاهد عملی در این شبکه | وضعیت API و محدودیت |
|---|---|---|
| دیوار | صفحه اصلی و `/s/tehran` با HTTP 200؛ endpoint داخلی `api.divar.ir/v8/web-search/tehran` با HTTP 503 | API رسمی «کنار» دارد، نیازمند برنامه و کلید/مجوز؛ اتصال رسمی احراز‌شده در این انتشار تست نشده است. |
| شیپور | صفحه اصلی و API دسته‌بندی `/api/v10.0.0/categories/compact` با HTTP 200؛ endpoint جستجو قابل اتکا تأیید نشد | استخراج HTML آزمایشی است. دریافت صفحه جستجو در یکی از آزمون‌ها `IncompleteRead` داشت. |
| ایسام | `https://api.esam.ir/api/items/v2/GetItemList?pageNumber=1` و `GetHomePageLatest?pageNumber=1` با HTTP 200 و JSON | خوراک عمومی تازه‌ها تأیید شد؛ keyword و پوشش تمام صفحات تأیید نشده‌اند. API غیررسمی وب، نه قرارداد توسعه‌دهنده. |
| کمدا | `https://search.komodaa.com/api/v2.6/search/products` با HTTP 200 و JSON؛ صفحه اصلی و `home-v2` نیز 200 | خوراک اولیه تأیید شد؛ پارامتر جستجو و صفحه‌بندی ثابت نشده‌اند. API غیررسمی وب. |
| سایر بازارها و شبکه‌های اجتماعی | اتصال تأییدشده در این بررسی ندارد | صرف وجود نام یا صفحه وب، پشتیبانی محسوب نمی‌شود. ورودی خوراک تأییدشده می‌تواند مسیر توسعه باشد. |

## دیوار: مسیر رسمی توسعه آینده

منابع رسمی: [SDK کنار](https://github.com/divar-ir/kenar-api)، [مستندات کنار](https://github.com/divar-ir/kenar-docs)، [پنل کنار](https://kenar.divar.dev/).

SDK رسمی endpoint `POST https://api.divar.ir/v1/open-platform/finder/post` و سربرگ `x-api-key` را تعریف می‌کند. داشتن endpoint به معنی مجوز دسترسی به همه آگهی‌ها نیست؛ سطح دسترسی، سهمیه و قرارداد را از کنار دریافت کنید. این پروژه کلید رسمی کاربر ندارد و موفقیت اتصال احراز‌شده را ادعا نمی‌کند.

## محدودیت خوراک عمومی

اگر فقط اولین صفحه تازه‌ها خوانده شود، فیلتر عبارت به‌صورت محلی انجام می‌شود؛ ممکن است کالای موردنظر شما در آن نمونه نباشد. «صفر تطبیق» در این حالت به معنی نبود کالا در کل بازار نیست. صفحه‌بندی و جستجوی کامل فقط با قرارداد تأییدشده باید اضافه شود. قیمت نامعلوم با صفر جایگزین نمی‌شود؛ واحد پول هر منبع باید مستقل تأیید شود.

## robots و شرایط

- [دیوار robots](https://divar.ir/robots.txt): مسیرهای حساب و الگوی جستجوی دارای q محدود شده‌اند.
- [شیپور robots](https://www.sheypoor.com/robots.txt): `/search` و الگوهای query محدودند.
- [ایسام robots](https://esam.ir/robots.txt): مسیرهای حساب، `/items/*` و الگوهای جستجوی `kw=` و `order=` محدودند.
- کمدا `/robots.txt` در آزمون HTTP 404 داشت؛ این به معنی اجازه استخراج نامحدود نیست.

شرایط رسمی: [دیوار](https://divar.ir/terms)، [شیپور](https://www.sheypoor.com/faq)، [ایسام](https://esam.ir/help/User%20agreement/%D8%AA%D9%88%D8%A7%D9%81%D9%82%D9%86%D8%A7%D9%85%D9%87-%DA%A9%D8%A7%D8%B1%D8%A8%D8%B1%DB%8C)، [کمدا](https://komodaa.com/blog/traditions/).

مجوز MIT مربوط به نرم‌افزار است، نه مالکیت داده آگهی‌ها، علائم تجاری یا اجازه مصرف تجاری API بازارها. اتصال‌های غیررسمی را برای استفاده محدود شخصی و پس از بررسی شرایط منبع فعال کنید. هیچ شماره تماس یا مشخصات شخصی فروشنده برای پایش کالا نگهداری نمی‌شود.

## محدودیت جغرافیایی

نتایج این شبکه الزاماً از داخل ایران تکرار نمی‌شوند. منشأ خطاهای 403/503 می‌تواند شبکه، gateway، محدودیت منطقه یا خود سرویس باشد؛ در این بررسی علت جغرافیایی قطعی اثبات نشده است. برنامه باید خطا را نشان دهد، نه اینکه داده نمونه یا نتیجه خالی موفق برگرداند.

## اتصال‌های پیاده‌سازی‌شده و آزمون نهایی

| اتصال | مسیر فعلی | نتیجه یک نوبت آزمایش واقعی |
|---|---|---|
| دیوار | استخراج کارت HTML عمومی `/s/{city}?q=...`، سپس تطبیق محلی | ۲۳ کارت، ۲۳ قیمت مشخص |
| شیپور | استخراج کارت HTML عمومی و تطبیق محلی؛ ممکن است keyword سمت سایت نادیده گرفته شود | ۲۶ کارت، ۱۹ قیمت مشخص |
| ایسام | خوراک عمومی ثابت صفحه اول؛ opt-in آزمایشی | ۱۰ کارت، ۱۰ قیمت مشخص |
| کمدا | خوراک عمومی ثابت صفحه اول؛ opt-in آزمایشی | ۱۸ کارت، ۱۸ قیمت مشخص |

نتیجه با `IRAN_MONITOR_TRUST_SYSTEM_DNS=1` در شبکه این دستگاه به‌دست آمد؛ حالت مستقیمِ پین IP با DNS مصنوعی شبکه ناسازگار بود و به‌درستی خطا داد. گزینه اعتماد به DNS سیستم فقط به چهار میزبان ثابت بازار محدود است. برای endpoint دلخواه feed/AI این استثنا اعمال نمی‌شود.

این جدول ناسازگاری پیشین endpoint جستجوی JSON دیوار/شیپور را انکار نمی‌کند: اتصال فعلی آن‌ها **HTML است، نه API رسمی یا قرارداد جستجوی JSON**. تعداد کارت استخراج‌شده، پوشش همه نتایج یا صحت معنایی همه آگهی‌ها را ثابت نمی‌کند.

ایسام و کمدا شهر را فیلتر نمی‌کنند؛ مقدار شهر نتیجه `unknown` است. خوراک ممکن است اقلام نو یا مزایده هم داشته باشد؛ صرفاً دست‌دوم بودن همه موارد تضمین نمی‌شود. ایسام قیمت مزایده را با توضیح مناسب علامت می‌زند. واحد هر دو خوراک از UI تومان تأیید شد. وضعیت‌های undocumented کمدا حدس زده یا فیلتر نشده‌اند.
