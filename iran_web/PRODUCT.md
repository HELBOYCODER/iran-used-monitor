# دست‌دوم‌بان
پنل عملیاتی فارسی و راست‌چین برای مدیریت پایش آگهی‌های دست‌دوم در ایران. کاربر پایش می‌سازد، منابع واقعی را می‌بیند، اسکن دستی اجرا می‌کند و نتایج را بررسی می‌کند. هیچ منبعی بدون پاسخ API متصل فرض نمی‌شود. داده نمایشی در برنامه وجود ندارد. رابط مستقل با HTML/CSS/JS و بدون وابستگی شبکه‌ای است. توکن طبق اصلاح قرارداد فقط در حافظه صفحه می‌ماند و با بارگذاری مجدد پاک می‌شود؛ هیچ ذخیره‌سازی مرورگری ندارد.

فرض‌های اجرایی به‌جای مصاحبه (وظیفه واگذارشده): استفاده روزمره در نمایشگر روشن، تمرکز بر خوانایی و کنترل؛ قیمت قرارداد بر حسب تومان نمایش داده می‌شود؛ واحد واقعی باید توسط backend تضمین شود. منابع و شهرها از حقیقت API و ورودی کاربر می‌آیند. محدوده تغییر صرفاً iran_web است.
